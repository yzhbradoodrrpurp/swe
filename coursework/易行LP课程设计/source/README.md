# 易行 LP：线性规划辅助建模与求解

作者：易治行，2023141220023。现代软件工程课程设计。

## 运行

直接用浏览器打开 `index.html`。无需安装依赖、注册账号或连接网络。交付目录还提供单文件版 `易行LP-直接打开.html`，功能相同。

如果环境限制本地文件，可在本目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，浏览器访问 `http://127.0.0.1:8765`。

## 操作

1. 载入教师 Tanner 示例，或输入自己的问题陈述。
2. 确定 max/min，填写活动名称、资源、单位消耗、资源限制、利润或成本。增加/删除活动与约束后，系数矩阵同步调整。
3. 点击“建模”，人工核对公式与业务含义。
4. 点击“计算规划方案”，查看最优值、活动水平、资源余量和迭代记录。
5. 修改参数后重新建模，旧计算上下文不会继续使用。
6. 问题陈述可导入 UTF-8 TXT。项目可导入/导出 JSON。方案可导出带原项目快照的 JSON。

## 支持范围

- 非负连续变量；max/min；≤、≥、=。
- 1～20 个活动，1～40 条原始约束；每个输入数字绝对值不超过 10^9。
- 原型菜单中的 <、> 保留为可选输入，但建模时明确阻止，不自动改成非严格不等式。
- 两阶段单纯形法，Bland 入基/平比值规则；最多 2000 次换基。
- 区分 optimal、infeasible、unbounded、iteration_limit、numerical_error。
- 不进行整数规划、自动自然语言解析、销量预测或灵敏度分析。资源余量不是影子价格。整数业务不能把连续解直接四舍五入后当成整数最优解。
- 数值计算使用 JavaScript 双精度浮点数；病态或尺度悬殊的模型可能需要更可靠的数值软件。当前没有真实用户验收和多人共享服务。

## 代码组织

- `index.html`：问题陈述、建模向导、公式和结果对话框。
- `style.css`：桌面与窄屏适配。
- `solver.js`：`LPModel` 与 `SimplexSolver`，可独立在 Node.js 中运行。
- `app.js`：`ModelView`、`SolveController`、`ModelRepository` 和事件绑定。
- `examples.js`：故事、最小化、无解和无界示例。Tanner 示例另在 `app.js` 定义。
- `test-solver.cjs`：16 个回归测试，含确定最优值与异常状态。
- `test-vertices.cjs`：100 个固定种子的二维问题，与独立顶点枚举结果对比。

## 复现测试

已安装 Node.js 时，在本目录运行：

```sh
node test-solver.cjs
node test-vertices.cjs
```

可在命令后追加一个 JSON 文件路径保存测试记录。浏览器测试由 Playwright 执行，实际输出与截图随课程设计项目的验证记录保存。
